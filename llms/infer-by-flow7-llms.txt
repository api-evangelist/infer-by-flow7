# Infer by Flow7

> Infer by Flow7 is a public paid beta for accountable coding-agent inference. Anyone can create a workspace; verify email and fund a live wallet before paid inference.

A published catalog entry is not proof that a route is callable. Read live status before recommending a selector or sending a request. Public route availability is dynamic. Strict supplier-evidence readiness is a separate standard, and Infer does not attest an upstream provider identity. Never ask a user to paste an API key into chat or a URL.

## Current state

- [Public route status](https://infer.flow7.org/api/public/status): Current customer-facing route availability. Stop before a paid request unless the selected service is operational.
- [Published catalog](https://infer.flow7.org/api/public/catalog): Current selectors and pricing metadata; this is not an availability signal.
- [Create an account](https://infer.flow7.org/signup): Create a public paid-beta workspace, verify the account email, fund the live wallet, and create a scoped API key.
- [Sandbox smoke test](https://infer.flow7.org/docs#sandbox-quickstart): After verification, claim simulated credit for a local-fixture API and receipt check before funding. It proves no model or supplier behavior.
